星星接接樂 — 執行說明

1. 解壓縮整個 StarCatcher 資料夾。
2. 在 VS Code 選「檔案 → 開啟資料夾」，選取 StarCatcher。
3. 直接用瀏覽器開啟 index.html 即可遊玩，不需要安裝套件。
4. 也可以在 VS Code 按 F5，以 Chrome 啟動遊戲。
5. 若已安裝 Live Server，可右鍵 index.html → Open with Live Server。

檔案：
index.html：網頁介面
style.css：外觀樣式
game.js：遊戲程式

操作：
方向鍵左右 / A、D：移動
滑鼠或手指：移動
空白鍵：開始 / 暫停 / 繼續
P：暫停 / 繼續
音符按鈕：切換音效

規則：60 秒內接星星，每顆 +10 分；碰到炸彈扣一條生命。共三條生命。
最高分儲存在目前瀏覽器。
